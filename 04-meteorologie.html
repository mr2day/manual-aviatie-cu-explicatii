#1. 228: Ce este vântul foehn?

Vântul foehn este o mișcare de aer care urcă pe un versant, apoi coboară pe partea cealaltă a abruptului, încălzindu-se și uscându-se.

Explicație detaliată

Aerul umed urcă pe versantul expus vântului, se răcește și lasă precipitații. Pe partea opusă coboară, iar prin comprimare se încălzește și devine uscat. Acesta este efectul de foehn, cunoscut ca vânt descendent cald și uscat pe versantul adăpostit.

    este o mișcare de aer orizontală de-a lungul văilor

    O mișcare de aer orizontală de-a lungul văilor.

    Detalii

    Aceasta descrie vântul de vale, nu foehnul.

  2. B
    este o mișcare de aer ce coboară seara de pe crestele montane înalte

    O mișcare de aer care coboară seara de pe crestele înalte.

    Detalii

    Aceasta descrie vântul catabatic, nu foehnul.

  3. C
    este o mișcare de aer ascendentă de-a lungul unui versant, după care își continuă mișcarea descensional, în partea cealaltă a abruptului

    O mișcare de aer ascendentă de-a lungul unui versant, după care își continuă mișcarea descendent, în partea cealaltă a abruptului.

    Detalii

    Este descrierea corectă a foehnului.

  4. D
    este o mișcare termică ce apare în văile înguste

    O mișcare termică ce apare în văile înguste.

    Detalii

    Aceasta descrie un vânt termic local, nu foehnul.

    Detalii

  3. C

    Detalii

    Detalii
